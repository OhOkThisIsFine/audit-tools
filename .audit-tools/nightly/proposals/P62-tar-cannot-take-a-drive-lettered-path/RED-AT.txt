GNU tar resolves FIRST, ahead of the drive-letter-safe system tar. GNU tar
parses a leading `host:` as a remote machine, so an archive path beginning
`C:\` is never opened as a file.

WHY CI IS GREEN AND THIS BOX IS RED: on Linux the archive path carries no drive
letter, so GNU tar reads it as an ordinary path. The defect is reachable only on
win32, which is why it shipped.
